1. ABSTRACT
====================================================================
The Hand Gesture Control System (Project Air) is a computer vision-based application designed to bridge the gap between human intent and computer interaction. The traditional hardware mouse is replaced with an intuitive, touchless interface powered by artificial intelligence. Using real-time hand tracking algorithms, the system translates spatial hand movements and specific finger pinches into precise PC commands (move, click, scroll, drag). By employing a robust physics-based smoothing filter (OneEuro filter) and intent-based confidence thresholds, the system ensures a jitter-free, reliable, and immersive holographic interaction experience.

3. INTRODUCTION
====================================================================
Human-computer interaction has traditionally relied on physical peripherals. Project Air reimagines this paradigm by leveraging a standard webcam as a sophisticated 3D sensor. The project's goal is to offer an accessible, hardware-free alternative for computer control, beneficial for users looking to reduce peripheral dependency, maintain sterile environments, or explore futuristic UI navigation.

4. TECHNOLOGY STACK
====================================================================
The project is built on a modern, modular Python stack:

• Programming Language: Python 3.8+
• Computer Vision Engine: OpenCV (cv2) - Responsible for camera interfacing, image processing, and rendering the holographic HUD.
• Machine Learning / Perception: Google MediaPipe Tasks API - Utilized the 'hand_landmarker.task' float16 model to detect 21 3D hand landmarks in real-time.
• System Control / Actuation: PyAutoGUI & pynput - Used to simulate hardware-level mouse events, cursor movement, and scrolling directly to the OS.
• Mathematical Processing: NumPy - Handles vector mathematics, distance calculations, and coordinate normalizations.
• Filtering: OneEuro Filter (Custom Implementation) - A real-time, low-pass filter used to eliminate high-frequency hand tremors.

5. SYSTEM ARCHITECTURE & ABSTRACTION
====================================================================
The system is heavily abstracted into modular subsystems to separate concerns:

[Webcam] -> (Perception Layer) -> (Intent Layer) -> (Control Layer) -> [Operating System]

1. Core Layer (system.py): The main event loop orchestrating the flow of data between perception, intent, and control subsystems.
2. Perception Layer (tracker.py & smoothing.py): Captures raw video frames and extracts the raw (X, Y, Z) coordinates of the 21 hand landmarks. Applies the OneEuro filter to clean the data.
3. Intent Layer (classifier.py): A state machine that evaluates the spatial relationship between fingers (e.g., Euclidean distance between thumb and index) against a confidence threshold to classify actions (Click, Scroll, Drag, Idle).
4. Control Layer (mouse_physics.py): Converts intent and normalized coordinates into physical screen pixels. Applies momentum, friction, and dynamic acceleration.
5. UI Layer (hud.py): Renders the diagnostic overlay (reticles, finger trails, status texts) back onto the video feed.

====================================================================
6. CORE FEATURES & IMPLEMENTATION
====================================================================
• Dynamic Cursor Movement: Mapped tip of the index finger (or palm center) to screen coordinates with physics-based smoothing.
• Left/Right Click: Detected via distance thresholds (< 8mm normalized) between Thumb tip and Index/Middle finger tips respectively. Includes a cool-down timer to prevent accidental double-clicks.
• Scrolling: Triggered by a "Peace Sign" classification (Index & Middle up, others down). Vertical translation of the hand dictates scroll velocity.
• Drag Mode: Detected via a full "Fist" classification. Toggles the PyAutoGUI mouse down state for seamless dragging.

8. CONCLUSION & FUTURE SCOPE
====================================================================
Conclusion:
Project Air successfully demonstrates the viability of utilizing standard consumer webcams for high-precision, touchless computer interaction. The modular architecture, coupled with advanced filtering, overcomes standard hurdles like hand jitter and accidental clicks, delivering a 100% working, production-grade interface.

Future Scope:
• Bi-manual Support: Expanding to track both hands for multi-touch gestures (e.g., pinch-to-zoom, rotating objects).
• Custom ML Models: Training personalized models to adapt to different hand sizes and environmental lighting.
• Dynamic Lighting Compensation: Better handling of low-light or backlit environments to maintain steady FPS.
